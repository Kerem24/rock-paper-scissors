# Rock, Paper, Scissors 🪨 📜 ✂️

A lightweight, terminal/browser-console Rock, Paper, Scissors game built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

This project was a hands-on exploration of JavaScript fundamentals—focusing on logic, functions, control flow, and user interaction.

---

## 💡 About the Project

The goal of this assignment was to build a classic game of Rock, Paper, Scissors played against the computer. It served as a milestone to practice writing clean, modular JavaScript code before moving on to DOM manipulation and UI design.

### What I Learned & Practiced

- **Function Decomposition:** Breaking the game logic down into reusable helper functions (`getComputerChoice`, `playRound`, `game`).
- **Conditionals & Logic:** Structuring clear `if/else` statements to evaluate win, loss, and tie conditions cleanly.
- **User Input & Normalization:** Handling string inputs from users using `.toLowerCase()` to make inputs case-insensitive.
- **State Management:** Tracking scores over a multi-round game loop.

---

## 🛠️ Built With

- **JavaScript (ES6+)** – Core game logic
- **HTML5** – Basic structure to run the script
